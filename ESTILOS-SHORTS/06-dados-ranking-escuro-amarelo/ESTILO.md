# Estilo 06 — dados ranking escuro amarelo

Referência: post DezYwoNydqk (@nikolasferreirabr) · 9:16 720x1280 30 fps
Post específico de referência (perfil de político, 22/10/2026). Usar SÓ o formato visual — tema político/pessoas reais é decisão do usuário.

## Visual
- **Infográfico 2D jornalístico em fundo preto** (#0B0B0C): rankings em barras horizontais com foto redonda + nome + cargo, gráfico de linha amarelo crescendo, mapa de pontos amarelos (MG), número gigante "3,1 MILHÕES" / "159 MILHÕES".
- Amarelo destaque #F5C518; secundárias cinza #3A3A3A, vermelho/azul pra comparação. Ícones de plataforma no título de cada gráfico.
- Linha destacada do ranking com contorno amarelo (o "7º" sobe na lista). Mosaico de miniaturas de vídeos com contagem.
- Logo minimalista no canto sup-esq (não copiar).

## Legenda
- Frase completa centralizada **abaixo do gráfico** (~62% da altura), sans branca (Inter semibold ~40px no 1080), **números em amarelo**. Sem caixa.

## Ritmo / voz
- Voz masculina jornalística, calma; troca de gráfico a cada ~8 s (lento), 151 s.
- Gancho 0-3 s: "Quando a gente coloca [X] num gráfico junto com outros..." — promessa de comparação por dados.
- Estrutura: dado-recorde → comparação com 3-5 rivais → engajamento por post → caso viral → ranking mundial → fecho com número surpreendente.

## Como replicar (grátis/local)
- HyperFrames puro (HTML/CSS/SVG + GSAP): barras animadas, linha SVG desenhada (stroke-dashoffset), contador numérico, mapa GeoJSON de pontos. **Dificuldade baixa** — o mais fácil de replicar com fidelidade.
- Fotos de pessoas: só em tema factual com imagem livre (Wikimedia); senão, iniciais em círculo.
