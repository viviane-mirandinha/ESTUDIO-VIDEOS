# ESTÚDIO DE VÍDEOS — LEIA-ME (versão 02/11/2026)

**Abra o `LEIA-ME.pdf`** (nesta pasta): é o passo a passo completo com prints — instalar, primeiro vídeo grátis, clonar um vídeo, todos os estilos/skills e problemas comuns.

## Resumo rápido
1. Extraia o zip numa pasta **sem acento e fora do OneDrive** (ex.: `C:\ESTUDIO-VIDEOS`).
2. Dê **2 cliques em `INSTALAR.bat`**. "O Windows protegeu o computador" → **Mais informações → Executar assim mesmo**. "Permitir alterações?" → **Sim**.
3. Espere aparecer **TUDO PRONTO** (15 min a 1 h). Não feche a janela preta.
4. Use o atalho **"Estúdio de Vídeos"** na área de trabalho.
5. Primeiro vídeo: **Criar → 🖼 Vídeo com imagens** → tema ou roteiro → estilo → **🎬 Fazer vídeo** → confira as imagens → **▶ Renderizar vídeo**.

## Requisitos
Windows 10/11 64 bits · 16 GB de RAM recomendado · placa NVIDIA opcional (acelera) · 15-30 GB livres · internet na 1ª instalação.
Nenhuma chave de API. Claude Pro/Max só para as skills de IA (aba 🤖 Estilos IA).

## Deu erro?
Leia a mensagem amarela **"O QUE FAZER"**, faça o que ela diz e rode `INSTALAR.bat` de novo (continua de onde parou). Não resolveu? Mande o `INSTALACAO.log` (nesta pasta) para o suporte.

Mais detalhes: `LEIA-ME.pdf`, `COMO-INSTALAR.pdf`, `CLAUDE.md` e `LICENCAS.md`.
